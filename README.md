# Кадры для космоса

Учебный проект: пять лабораторных по нейронным

Доска задач: https://github.com/users/knfwsss/projects/1

В каждой лабораторной десять карточек, по одной на человека. На карточке указаны исполнитель и роль. Во всех работах используется второй датасет из методички.

| Лабораторная | Датасет |
|---|---|
| ЛР1. Регрессия | NASA PCoE Battery Dataset |
| ЛР2. Классификация | SMAP (THULab/SMAP) |
| ЛР3. CNN | Satellite Image Classification Dataset |
| ЛР4. LSTM | XJTU-SPS |
| ЛР5. Автоэнкодер | Flying Laptop Case Study |

Команда: Гарбузова, Бурова, Монахова, Лукавенко, Гребенец, Цыхоня, Попова, Шмидт, Ерцкина, Толмачева.

## Роли по лабораторным

Роли меняются от работы к работе: за пять лабораторных у каждого пять разных ролей, и общий объём задач примерно одинаковый.

| | ЛР1 | ЛР2 | ЛР3 | ЛР4 | ЛР5 |
|---|---|---|---|---|---|
| Гарбузова | Данные и лицензия | Состав набора | Предобработка | Графики | Обучение |
| Бурова | Состав набора | Предобработка | README и сдача | Обучение | Метрики |
| Монахова | Предобработка | Разбиение выборки | Метрики | README и сдача | Разбор ошибок |
| Лукавенко | Разбиение выборки | Архитектура сети | Графики | Разбор ошибок | Данные и лицензия |
| Гребенец | Архитектура сети | Обучение | Разбор ошибок | Предобработка | Графики |
| Цыхоня | Обучение | Метрики | Данные и лицензия | Разбиение выборки | README и сдача |
| Попова | Метрики | Графики | Архитектура сети | Данные и лицензия | Состав набора |
| Шмидт | Графики | Разбор ошибок | Состав набора | Архитектура сети | Предобработка |
| Ерцкина | Разбор ошибок | README и сдача | Обучение | Состав набора | Разбиение выборки |
| Толмачева | README и сдача | Данные и лицензия | Разбиение выборки | Метрики | Архитектура сети |

Задача каждой роли расписана на карточке доски.

Сырые датасеты в репозиторий не коммитятся.
