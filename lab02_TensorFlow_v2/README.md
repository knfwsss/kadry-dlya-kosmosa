# lab02_TensorFlow_v2 — классификация состояний подсистем SMAP, вторая версия

Бинарная классификация окон телеметрии спутника SMAP: **0 — норма, 1 — неисправность**. Полносвязная сеть в TensorFlow/Keras, балансировка SMOTE, сравнение с логистической регрессией.

Первая версия работы лежит в [lab02_TensorFlow](../lab02_TensorFlow). Во второй версии выборка разбита целыми блоками по 5 000 отсчётов, а не по времени. Файл test склеен из записей разных подсистем, и при разбиении по времени в тест попадали подсистемы, которых не было в обучении. Кроме того, во второй версии дисбаланс классов обрабатывается через SMOTE, добавлен baseline на логистической регрессии и ответы на контрольные вопросы.

## Результаты на test, порог 0,5

| Модель | Accuracy | Precision | Recall | F1 | ROC-AUC | PR-AUC |
|---|---:|---:|---:|---:|---:|---:|
| Всегда «норма» | 0,876 | 0 | 0 | 0 | — | — |
| Логистическая регрессия | 0,496 | 0,184 | 0,888 | 0,304 | 0,712 | 0,238 |
| Нейронная сеть 150 → 64 → 32 → 16 → 1 | 0,676 | 0,207 | 0,567 | 0,303 | 0,733 | 0,377 |

Найдено 14 аномальных участков из 16. На четырёх разных раскладках блоков ROC-AUC сети 0,62–0,73, логистической регрессии 0,51–0,71. При разбиении по времени, на подсистемах, которых не было в обучении, обе модели ниже случайного угадывания (0,38 и 0,41).

## Запуск

```text
pip install tensorflow scikit-learn imbalanced-learn pandas matplotlib seaborn jupyter
jupyter notebook lab2_classification_nn.ipynb
```

Jupyter запускают из этой папки. Ноутбук читает данные из `data/cache/smap.npz`. Исходные файлы `SMAP_train.tsfile` и `SMAP_test.tsfile` лежат в `../lab02_TensorFlow/data/raw/`; если кэша нет, скопируйте их в `data/raw/` и установите `tsfile`.

Проверено на Python 3.9 и TensorFlow 2.15.
